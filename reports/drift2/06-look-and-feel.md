Method: `python3 -m aitracker --serve` on port 8797 (fresh start after checkout), driven with
Playwright (chromium) via scripts in the visual scratchpad (`measure.js`/`measure2.js`/`measure3.js`,
same localStorage-init pattern as `verify.js`). All values below are **computed styles read off the
live DOM** (`getComputedStyle`), not source CSS, at 1440×1024 and 1280×900, light and dark theme,
board and detail view. Screenshots: `m-board-{light,dark}-{1440,1280}.png`, `m2-detail-light-1440.png`.

wrapping behaviour, ratios, and rendered content mapping. It does not re-litigate token hex values
already exhaustively verified by `01-foundations.md`'s re-audit in this same directory (confirmed
here too: every light/dark token this harness sampled — 37 tokens across both themes — came back an

## Fix list (ordered by severity)

1. **HIGH** — `aitracker/web/ext_cr_board.css:298` (`@media (max-width: 1439px) { .cr-topbar { flex-wrap: wrap; ... } }`): stop wrapping the top bar into two rows across 1280–1439px. Extend the icon-only-label compaction currently reserved for `@media (max-width: 480px)` (collapsing text labels on Back/Config/Help/New session, tightening `.cr-dest-pills` gap) up through 1439px instead, so `.cr-topbar` stays a single `height:54px` row at every width ≥1280px per `02-shell-and-board.md:93-95`.
2. **HIGH** — `aitracker/web/ext_cr_detail.js:1743-1749`: when `session.overview.goal` is non-empty, put that text (not `sessionName`) into `.crd-goal`; keep the title-fallback path only when goal is empty, and drop (or genuinely demote to a metadata line) the separate `.crd-goalline` element — per `03-detail-view.md:76`.
3. **MED** — `aitracker/web/ext_cr_detail.css:858-862` (`.crd-summary-label`): change `color: var(--text-eyebrow)` to `color: var(--text-muted)` to match `03-detail-view.md:216`'s explicit "muted label" wording.
4. **MED** — `aitracker/web/ext_cr_detail.css:163` (`.crd-goal`): raise `font-size: 27px` to at least `29px` to land inside `01-foundations.md:252`'s 29–32px range.
5. **MED** — `aitracker/web/ext_cr_detail.css:858-862` (`.crd-summary-label`): add `font-weight: 600` to match the same weight every other eyebrow rule in this file already declares (`.crd-col-eyebrow:662`, `.crd-panel-label:718`).
